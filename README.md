# 📈 Text-Analyzer
Ruled Based - AI for analyze any content and detect the positive/negative words then return the result on terminal 

-------------------------------------------
# ⁉️ How it will work ?
1- The user will enter any word , sentence or text file.  
2- The program will take the content first and check if it file path or just a text.  
3- Then will convert each word to lowercase.  
4- Check if the words are positive or negative.  
5- Count the number of negative and positive words  
6- Give all result about that content
